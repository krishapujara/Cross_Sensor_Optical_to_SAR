## 1. Project Overview

This research application implements an end-to-end deep learning system that translates **multispectral optical satellite imagery (Sentinel-2 MSI)** into **synthetic Synthetic Aperture Radar (SAR) imagery (Sentinel-1 C-band)** using a conditional generative adversarial network (**Pix2Pix CGAN**).

The system addresses fundamental challenges in satellite Earth observation:
* **All-Weather Capability:** Synthesizing radar backscatter estimates over cloudy optical scenes during monsoons and disasters.
* **Cross-Sensor Data Fusion:** Bridging the spectral and radiometric gap between optical surface reflectance ($0.4 - 2.2\,\mu\text{m}$) and microwave backscatter ($5.4\,\text{GHz}$).
* **Selective Remote Data Access:** Streaming and selective retrieval without downloading multi-hundred-gigabyte datasets.

> **⚠️ SCIENTIFIC DISTINCTION:**  
> A synthetic SAR image generated by a deep learning model is a **statistical visual estimation**. It is **NOT** a physical radar acquisition and cannot replace genuine SAR observations or serve as calibrated microwave proof.

## 3. Architecture & Technical Highlights

* **Generator:** U-Net 256 with 8-scale downsampling, 8-scale upsampling, skip connections, and Tanh activation.
* **Discriminator:** $70 \times 70$ PatchGAN assessing local spatial consistency and speckle texture.
* **Loss Functions:** Combined Minimax Adversarial Loss + L1 Reconstruction Loss ($\lambda_{L1} = 100.0$).
* **Evaluation Suite:** Exact PSNR (dB), SSIM, MAE, MSE, and thermal residual error maps.
* **Product Export:** High-contrast 8-bit PNG images and calibrated 32-bit float GeoTIFFs.
